# Contributing

Thanks for your interest in contributing to this repository.

## Before you start
- Open an issue to discuss significant changes before submitting a pull request.
- Keep pull requests focused; one concern per PR.

## How to contribute
1. Fork the repository and create a branch from the default branch.
2. Make your changes with clear commit messages.
3. Ensure the project builds / tests pass locally.
4. Open a pull request using the PR template and link any related issues.

## Code style
Follow the existing style in the repository. Run any available linters or
formatters before submitting.

## Reporting issues
Use the issue templates (bug report / feature request) and include enough
detail to reproduce or understand the request.
